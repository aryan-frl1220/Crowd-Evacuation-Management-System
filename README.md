The Crowd Evacuation Management System is a console-based project developed in C language that helps simulate and manage emergency evacuation processes in crowded areas. The project is designed to find safe and efficient evacuation paths for people during emergencies such as fires, accidents, or natural disasters. It uses graph-based algorithms and data structures to calculate the shortest and safest routes from different locations to emergency exits.

The system provides features such as area mapping, route calculation, crowd movement management, and emergency exit handling through a menu-driven interface. File handling and modular programming concepts are used to maintain data efficiently and keep the program organized. This project demonstrates the practical application of algorithms, problem-solving techniques, and real-world emergency management concepts while improving safety and evacuation planning in crowded environments.
